## QuizApp
A free, open-source equivalent of Quizlet for learning foreign languages, terms, definitions, and exam preparation.
Main features:
- Create and edit training modules with flash cards.
- Splitting the cards into convenient blocks of 8 pieces.
- Memorization mode with two learning paths: exam preparation and long-term memorization using the interval repetition algorithm (SM-2 / Anki).
- Combined knowledge test: choosing an answer in the test and typing on the keyboard.
- Voicing of terms and definitions (TTS) with automatic detection of Russian and English.
- Built-in AI tutor and card generator (supports Google Gemini, OpenAI ChatGPT, Anthropic Claude, DeepSeek and OpenRouter via its own API key).
- Import and export of training modules.
